# 🏥 Hospital Data Analytics Dashboard

A comprehensive **Hospital Analytics Dashboard** developed using Microsoft Power BI to analyze patient demographics, hospital departments, revenue, insurance coverage, admissions, and patient outcomes.

## 📊 Project Overview

This project transforms hospital data into interactive dashboards that help analyze:

* Patient demographics and distribution
* Department and doctor performance
* Hospital revenue and insurance coverage
* Admission trends and types
* Patient outcomes and readmissions
* Patient satisfaction

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Modeling
* Excel

## 📑 Dashboard Pages

1. **Hospital Executive Summary**
2. **Patient & Demographics**
3. **Department & Doctor Analysis**
4. **Financial & Insurance Analysis**
5. **Admission & Outcome Analysis**

## 🔍 Key Features

* Interactive slicers and filters
* KPI cards for important metrics
* Monthly patient and revenue trends
* Department-wise analysis
* Insurance coverage and patient payment analysis
* Patient outcome and readmission analysis
